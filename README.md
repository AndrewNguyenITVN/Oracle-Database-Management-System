## 📌 Course Overview  
This project demonstrates how to design, implement, and query a relational database using **Oracle DBMS**. It includes table creation, data insertion, indexing, and query optimization using SQL and PL/SQL.


The course reinforces fundamental concepts of computer networking introduced in the theory course, including:
- Relational Database Design  
- Entity Relationship Diagram (ERD)  
- SQL: `CREATE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`  
- Views, Triggers, Indexes  
- Joins and Subqueries  
- PL/SQL Procedures and Functions  
- Query Optimization (Execution Plans, Indexing)
- ...
